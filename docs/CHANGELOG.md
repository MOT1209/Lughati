# سجل التغييرات

## غير منشور — الترقية إلى Expo SDK 58
- Expo SDK 58، React Native 0.88، React 19.3 (من الطلب ‎#26)، ومغادرة الاختبار عبر `usePreventRemove`.
- اختبارات RNTL 14: كل `render`/`fireEvent`/`act` غير متزامنة، `test-renderer` بدل `react-test-renderer`، واستبدال استعلامات `UNSAFE_*`.
- `renderRouter` في Expo Router 58 يفعّل مؤقتات Jest الوهمية فتتعلّق الضغطات؛ `jest.setup.ts` يجعلها تتقدّم تلقائياً.
- يحتاج الهاتف **Expo Go لـ SDK 58** (الإصدار 57 لا يفتح المشروع).

## غير منشور — تنظيف ومراجعة (2026-11-23)
- لوحة المشرف: الخادم يرفض حظر حساب مشرف (`cannot_ban_admin`)، والحساب المحظور لا يستطيع استدعاء البوابة برمز قديم.
- سر اختياري `OPENCODE_ZEN_MODELS_URL` لقائمة النماذج (AI12).
- نُقلت التقارير والخطط القديمة و`test-report/` إلى `docs/archive/`؛ حُدّث `AGENTS.md` ليطابق الواقع.

## غير منشور — نظام الذكاء الاصطناعي الموحّد
- بوابة واحدة `ai-gateway` (Edge Function) لست ميزات: معلّم شخصي، شريك محادثة، مدرّب كتابة، تمارين ذكية، تدريب نطق، مخطط تعلّم؛ شاشات `/ai/*`.
- سجل نماذج وتوجيه في قاعدة البيانات (كل النماذج المرشّحة معطّلة وغير موثَّقة)، قاعدة «موثَّق + مجاني + مفعّل + صحي» ولا مدفوع بلا إذن، احتياطي، صحة النموذج، إدارة بلا تحديث للتطبيق.
- حدود ذرّية على الخادم (`ai_reserve`)، تتبّع الاستخدام والتكلفة، كاش وإعادة استخدام التمارين.
- هجرة `20261104000001_ai_platform.sql` (11 جدولاً + RLS) مطبَّقة على المشروع الحي؛ اختبار RLS الحي نجح.
- استُبدل `ai-tutor`/`AIProvider` القديم؛ حُدّثت سياسة الخصوصية وData Safety (المحادثات تُخزَّن).
- 41 اختبار بوابة + 41 اختبار تطبيق/شاشات جديدة.
