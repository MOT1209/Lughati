# سجل التغييرات

## غير منشور — نظام الذكاء الاصطناعي الموحّد
- بوابة واحدة `ai-gateway` (Edge Function) لست ميزات: معلّم شخصي، شريك محادثة، مدرّب كتابة، تمارين ذكية، تدريب نطق، مخطط تعلّم؛ شاشات `/ai/*`.
- سجل نماذج وتوجيه في قاعدة البيانات (كل النماذج المرشّحة معطّلة وغير موثَّقة)، قاعدة «موثَّق + مجاني + مفعّل + صحي» ولا مدفوع بلا إذن، احتياطي، صحة النموذج، إدارة بلا تحديث للتطبيق.
- حدود ذرّية على الخادم (`ai_reserve`)، تتبّع الاستخدام والتكلفة، كاش وإعادة استخدام التمارين.
- هجرة `20261104000001_ai_platform.sql` (11 جدولاً + RLS) مطبَّقة على المشروع الحي؛ اختبار RLS الحي نجح.
- استُبدل `ai-tutor`/`AIProvider` القديم؛ حُدّثت سياسة الخصوصية وData Safety (المحادثات تُخزَّن).
- 41 اختبار بوابة + 41 اختبار تطبيق/شاشات جديدة.

## غير منشور — فرع `ccr-a207c4f4-n7w7f1`
**جديد**
- واجهة خلفية Supabase: هجرات، RLS، بذر الكتالوج، `supabase/tests/rls.sql`.
- `SupabaseAuthService`: تسجيل، دخول، خروج، تحقق بريد (إعادة إرسال)، استعادة كلمة المرور، حذف الحساب؛ جلسة في SecureStore.
- شاشة «نسيت كلمة المرور» وشاشة «تحقق من بريدك» وزر «حذف الحساب».
- مزامنة سحابية حالة-إلى-حالة وترحيل AsyncStorage مع التحقق (`docs/SYNC.md`).
- المعلّم الذكي: دالة `ai-tutor`، `RemoteAIProvider`، شاشة، حدود معدّل، تتبّع الاستخدام.
- الصوت: إيقاف عند الخلفية، واختيار الصوت الأنسب للغة.
- بوابات جودة المحتوى (29 اختباراً).
- CI: `expo-doctor`، فحص أسرار، وظيفة قاعدة البيانات.

**تغيّر**
- `AuthService.signUp` يعيد `{ session, needsEmailVerification }`.
- `AIProvider.reply` ← `AIProvider.ask(request)` مع `source: 'ai' | 'mock'`.
- خارج وضع التطوير وبلا إعداد خلفية لا يوجد دخول (لا مصادقة وهمية في الإنتاج).
- سياسة الخصوصية وData Safety وإعلان المتجر أُعيدت كتابتها للحساب السحابي.

**أُصلح**
- مؤقّت `restoreBeforeLoad` كان يترك مقبضاً مفتوحاً في الاختبارات.
