# اختبار الذكاء الاصطناعي

كل الاختبارات الآلية تستخدم **ردوداً مُحاكاة** (لا طلبات حية ولا تكلفة). الاختبار الحي **لم يُجرَ** (لا مفتاح، وبيئتي تحجب `opencode.ai` و`supabase.co`).

## الأوامر
```bash
npm run typecheck                         # التطبيق + وحدات الخادم (tsconfig.functions.json)
npm test -- --runInBand                   # يشمل supabase/functions/**/*.test.ts
npx jest supabase/functions/ai-gateway    # الخادم فقط
npx jest src/services/ai src/navigation/aiScreens
psql "$DB_URL" -v ON_ERROR_STOP=1 -f supabase/tests/rls.sql   # RLS بما فيه جداول الذكاء الاصطناعي
```

## ما يغطيه (supabase/functions/ai-gateway/gateway.test.ts — 41 اختباراً)
- **النماذج:** رفض غير الموثَّق/المعطّل/مجهول السعر/المدفوع/الواقع حديثاً؛ التخطيط أساسي ثم احتياطي؛ معرّف غير صالح (404)؛ حدّ المعدّل (429)؛ الفشل والمهلة؛ الاحتياطي؛ سقف المحاولات؛ لا نموذج مدفوع صامت.
- **المزوّد:** ترويسة المصادقة على الخادم، قراءة الاستخدام، تحويل الأخطاء بلا تسريب، المهلة.
- **التحقق من المخرجات:** استخراج JSON، الكتابة (قيم الطلب تتغلب)، التمارين (تكرار/غموض/إجابة مفقودة/فراغ)، المحادثة، النصائح، المخطط.
- **الميزات الست عبر المعالج الكامل:** المعلّم (محادثة+كاش+تاريخ من الخادم+ملكية)، المحادثة، الكتابة (بنية صالحة/رفض غير صالح)، التمارين (تخزين وإعادة استخدام)، النطق (بلا نموذج عند التطابق، نصائح عند الاختلاف، المقارنة عند غياب النصائح)، المخطط (تخزين، رفض إحصاءات مختلَقة).
- **الإدارة:** مغلقة للمستخدم العادي، رفض تفعيل غير موثَّق، توجيه بلا تحديث للتطبيق، `refresh` للصحة فقط.

## التطبيق (src/services/ai/ai.test.ts — 27، src/navigation/aiScreens.test.tsx — 14)
تنظيف المدخلات، رفض التالف، سياق بلا هوية، التمارين (رفض إجابة خارج الخيارات)، تصحيح الإجابات (عربي/ديكريتك)، المخطط (فارغ/ضعيف/متوازن)، العميل (كل رموز HTTP، المهلة، بلا خلفية = «غير متاح» لا ردّ مزيف)، والشاشات: الرئيسية بالعربية، المعلّم (سياق، استمرار المحادثة، خطأ + إعادة، غير متاح)، المحادثة، الكتابة، التمارين، النطق، المخطط.

## قاعدة البيانات الحية
`AI RLS TESTS PASSED` على المشروع الحي (عزل المستخدمين، منع كتابة العملاء، عدم قراءة السجل/التوجيه/الكاش، حدود `ai_reserve` الذرّية والتجاوز لكل مستخدم).
