# معمارية الذكاء الاصطناعي

```
التطبيق (شاشات الميزات الست)
   │  src/services/ai/features.ts  — تنظيف المدخلات، التحقق من الرد
   ▼
AIGateway (src/services/ai/gateway.ts) ── supabase.functions.invoke('ai-gateway')
   ▼
Edge Function ai-gateway (supabase/functions/ai-gateway/)
   handler.ts: مصادقة → تحقق من الطلب → كاش/إعادة استخدام → حدود ذرّية → توجيه → مزوّد → تحقق من المخرجات → حفظ + تسجيل
   │
   ├─ registry.ts   من يُسمح باستدعاؤه (verified + free + مفعّل + صحي)
   ├─ provider.ts   استدعاء متوافق مع OpenAI chat/completions (المفتاح من أسرار الخادم فقط)
   ├─ prompts/*     برومبتات الميزات الست (نسخة موحّدة PROMPT_VERSION)
   └─ schemas.ts    التحقق من مخرجات JSON
   ▼
OpenCode Zen  →  نموذج مجاني أساسي → نموذج مجاني احتياطي  (لا نموذج مدفوع دون إذن صريح)
```

التطبيق **لا يتصل بالمزوّد أبداً** ولا يحمل أي مفتاح. كل الميزات الست تمر عبر دالة واحدة وجدول توجيه واحد، فلا تكامل مستقل لكل ميزة.

## مسار الطلب (الترتيب مقصود: الأرخص أولاً)
1. **المصادقة:** هوية المستخدم من رمز الجلسة (لا من الجسم). `verify_jwt` مفعّل.
2. **التحقق من الطلب** (`request.ts`): الميزة/اللغة/المستوى من قوائم ثابتة، سقوف الأطوال، إزالة محارف التحكم، تجاهل أي حقول زائدة (لا system prompt ولا user id من العميل).
3. **إعادة الاستخدام قبل الإنفاق:** تمارين مخزّنة (`ai_generated_exercises`) تُعاد بلا طلب للنموذج؛ أسئلة المعلّم القصيرة المتكررة من `ai_explanation_cache`؛ مقارنة النطق عند تطابق كل الكلمات محلياً بلا نموذج.
4. **حد ذرّي على الخادم:** `ai_reserve()` (قفل استشاري لكل مستخدم) يعدّ الطلبات في الدقيقة واليوم ويحجز صفاً في `ai_usage_logs` قبل أي استدعاء. يتجاوز الحد الافتراضي صفّ `ai_user_limits` إن وُجد.
5. **التوجيه:** `ai_task_routing` يعيّن (أساسي، احتياطي) لكل ميزة؛ `planAttempts` يختار المسموح فقط، بحد أقصى **محاولتين** لكل طلب.
6. **الاستدعاء + التحقق:** مهلة 20 ث، إعادة محاولة واحدة فقط إن لم يوجد احتياطي والخطأ عابر (مهلة/5xx)؛ مخرجات JSON تُتحقق ضد مخطط، وما لا يُقبل يُحتسب محاولة فاشلة وينتقل للاحتياطي.
7. **الحفظ والتسجيل:** المحادثة والرسائل، تصحيحات الكتابة، التمارين (تُزال تكراراتها بـ `content_hash`)، التوصيات؛ ثم تحديث صف السجل: النموذج، فئة السعر **من السجل لا من العميل**، الرموز، المدة، الحالة.

## الميزات الست → مهام التوجيه
`tutor`, `speaking`, `writing`, `quiz`, `pronunciation`, `planner`. التفاصيل في `AI_FEATURES.md`.

## سياق المتعلّم
`buildAIContext` (التطبيق) يرسل لغة التعلّم ولغة الشرح والمستوى وحتى 5 مواضيع ضعف وهدفاً اختيارياً. لا اسم ولا بريد ولا معرّف ولا سجل كامل. الإحصاءات (المخطّط) تُحسب محلياً بمنطق عادي (`buildPlannerStats`) ويفسّرها النموذج ولا يحسبها. المحادثة تُقرأ من الخادم (آخر 6 رسائل، 500 حرف لكل منها) فلا يمكن للعميل حقن تاريخ مزوَّر.

## ما لم يُبنَ (انظر AI_KNOWN_ISSUES.md)
تسجيل الصوت وتحويله إلى نص (لا مزوّد STT)، تقييم نطق على مستوى الفونيم، نموذج مدفوع افتراضي، لوحة إدارة بصرية (الإدارة عبر واجهة برمجية).
