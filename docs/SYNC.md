# المزامنة والترحيل

## المبدأ
مزامنة **حالة-إلى-حالة** متماثلة القدرة: اسحب حالة الخادم → ادمجها مع المحلي بالقواعد أدناه → اكتب المحلي → ادفع ما ينقص الخادم → تحقق. لا سجل عمليات يُعاد تشغيله، لذلك المحاولات المقطوعة والمكررة والعودة بعد انقطاع طويل كلها تتقارب إلى النتيجة نفسها. «الطابور» هو الفرق بين المحلي والخادم، ويبقى على الجهاز حتى ينجح الدفع.

الشيفرة: `src/services/sync/` (`merge.ts` قواعد صرفة، `engine.ts` المحرك، `SupabaseCloudStore.ts` الخادم، `index.ts` الربط). المشغّلات: بعد تسجيل الدخول، عودة التطبيق للمقدمة، عودة الاتصال (NetInfo)، وبعد تغيّر التقدم (تأخير 2.5 ث) — `hooks/useSyncTriggers.ts`. استدعاءات متزامنة لنفس المستخدم تشترك في تشغيل واحد.

## قواعد حل التعارض
| البيانات | القاعدة |
|---|---|
| محاولات الاختبار | اتحاد حسب `id` (إلحاق فقط، لا تضيع) |
| الدروس المكتملة | اتحاد |
| XP / الكلمات / الدقائق | الأكبر (عدّادات تنمو؛ الأكبر لا يفقد تقدماً) |
| المستوى | الأعلى |
| أيام النشاط | الأكبر لكل حقل في اليوم نفسه؛ السلسلة = اتحاد الأيام |
| مراجعات المفردات | الحالة ذات `lastReviewedAt` الأحدث |
| ملف اللغات، الإعدادات، الهدف اليومي | إن وُجد جانب واحد فقط استُخدم؛ وإن اختلفا: ما غيّره المستخدم هنا منذ آخر مزامنة يفوز، وإلا فقيمة الخادم. صفّ إعدادات الخادم الافتراضي لا يطغى على اختيار محلي حقيقي. لغة الواجهة المسحوبة لا تُطبَّق إن اختار المستخدم لغة محلياً (تغيير الاتجاه يحتاج إعادة تشغيل) |

**حدود معروفة:** جهازان يعملان على اليوم نفسه دون اتصال يأخذان الأكبر لا المجموع (قد يُحسب XP مشترك بأقل من مجموعه). نفضّل عدم فقدان التقدم على الدقة الحسابية.

## ترحيل بيانات AsyncStorage
أول مزامنة لحساب فيه بيانات محلية ولم يُتحقق ترحيله:
1. كشف البيانات المحلية للحساب الموقَّع فقط (مفاتيح `userId:*`، لا بيانات حسابات أخرى على الجهاز).
2. تسجيل `sync_migrations.status = started` (جهاز+حساب).
3. دمج + رفع (upsert متماثل القدرة؛ المحاولات `ignoreDuplicates`).
4. **تحقق:** إعادة قراءة الخادم والتأكد أن كل محاولة/يوم/مراجعة/درس محلي موجود. إن فشل التحقق يُرفع خطأ ولا يُسجَّل النجاح.
5. تسجيل `verified` محلياً وعلى الخادم.
لا يُحذف شيء محلي ولا يُعاد كتابة التخزين المحلي بسبب الرفع. إن انقطع الأمر بقي `started` وأُعيد وتُحقِّق في التشغيل التالي.

الاختبارات: `src/services/sync/sync.test.ts` (ترحيل، تكرار/تزامن، بلا اتصال، انقطاع منتصف الترحيل، جهاز ثانٍ، جهازان، عزل الحسابات، رفض الوصول، محتوى أحدث).
