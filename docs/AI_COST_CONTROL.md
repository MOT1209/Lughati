# ضبط التكلفة

السياسة: **مجاني أولاً، ولا مدفوع بلا إذن صريح.**

| الآلية | أين | تحقق |
|---|---|---|
| لا استدعاء إلا لنموذج موثَّق ومجاني ومفعّل وصحي | `registry.ts` | `gateway.test.ts` (7 اختبارات توجيه، «never silently uses a paid model») |
| نموذج مدفوع فقط بـ `allow_paid` صريح في مسار المهمة، والمجاني يسبقه | `ai_task_routing`, `planAttempts` | اختبار |
| حدّ أقصى **محاولتان** لكل طلب مستخدم؛ إعادة محاولة واحدة فقط بلا احتياطي وللأخطاء العابرة؛ الإخراج غير الصالح ينتقل للاحتياطي ولا يُكرَّر | `handler.ts: generate` | اختبارات |
| حد يومي ودقيقة لكل مستخدم، **ذرّي على الخادم** (قفل استشاري)، مع تجاوز لكل مستخدم `ai_user_limits` | `ai_reserve()` | `supabase/tests/rls.sql` (نُفِّذ حياً: ok, ok, minute, daily, override) |
| سقوف: رسالة 800، نص كتابة 1200، سجل 6×500، جسم 24KB، مخرجات = الأصغر بين المسار و`AI_MAX_OUTPUT_TOKENS` | `request.ts`, `handler.ts` | اختبارات |
| مهلة 20 ث لكل استدعاء | `provider.ts` | اختبار |
| إعادة الاستخدام: تمارين مخزّنة، كاش شرح للأسئلة القصيرة، مقارنة نطق محلية عند التطابق، إحصاءات المخطّط محلية | `handler.ts`, `learnerContext.ts` | اختبارات |
| سياق موجز: لا تاريخ كامل، 5 مواضيع ضعف كحد أقصى | `learnerContext.ts` | اختبار |
| تسجيل لكل طلب: المستخدم، النموذج، الميزة، رموز الإدخال/الإخراج، المدة، النجاح/الفشل، فئة السعر | `ai_usage_logs` | اختبار + RLS |
| **السعر من السجل لا من العميل** | `finalizeLog` يأخذ `pricingTier` من `ai_model_registry` | اختبار |
| عند نفاد الحد/الغياب: رسائل واضحة بلا بدائل مدفوعة | الواجهة `ai.errors.*` | اختبارات الشاشات |

**مراقبة:** `select feature, model_id, pricing_tier, sum(input_tokens), sum(output_tokens), count(*) from ai_usage_logs where created_at > now() - interval '1 day' group by 1,2,3;`

**حدود معروفة:** أسعار الرموز في السجل (`input_price_per_mtok`…) معلوماتية؛ لا حساب تكلفة تلقائي لأن النماذج المجانية بلا سعر. طلبات `cache_hit` تُسجَّل ولا تُحتسب ضد الحد.
